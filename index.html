Flood rate monitoring system

The system uses an ultrasonic sensor to measure the distance between the surface of the water and the sensor. The ultrasonic sensor is connected to an Arduino microcontroller which processes distance readings and determines the current water level. It has a buzzer for warning. It also has a user interface to alert the user when the water levels are not safe.
